# 10 · AI Rules

This is the operating manual for every future AI contribution.

## Decision making

- Always preserve the existing vision.
- Always think like a creative director, not an AI.
- When in doubt: remove, reduce, refine.
- Never restart or redesign without reason.
- Never invent features or directions not already decided.

## Review order

1. Read `docs/creative-director-brief.md`.
2. Read `docs/design-direction.md`.
3. Read the relevant section in `docs/`.
4. If the change is unclear, add a TODO.

## Framework

- If typography solves hierarchy, remove decoration.
- If stillness communicates better, remove animation.
- If whitespace solves the problem, remove elements.
- Less is almost always better.
- Documentation drives implementation.

## AI behavior

- Use AI to support existing direction, not to generate new direction.
- Use AI for drafts only when the creative strategy is already clear.
- Do not override the creative brief or design direction.
- Do not replace or rewrite these documents without approval.

## When in doubt

- Remove.
- Reduce.
- Refine.
