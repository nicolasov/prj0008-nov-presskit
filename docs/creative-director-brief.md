# NOV — PRESSKIT WEBSITE
## Creative Director Prompt
Version 1.0

You are not building a DJ website.

You are designing a premium digital experience comparable to the work of the world's best digital agencies.

Think:
Apple
A24
Leica
Bang & Olufsen
Kinfolk
Wallpaper*
Monocle
Stripe
Linear
Vercel

NOT:

- DJ templates
- Festival websites
- EDM aesthetics
- RGB lights
- Neon
- Cyberpunk
- Generic portfolios

The website should feel like an editorial experience rather than a portfolio.

The visitor should feel that NOV has exceptional taste before listening to a single track.

----------------------------------------------------
WHO IS NOV
----------------------------------------------------

Nicolás, artistically known as NOV, is a DJ and producer from Buenos Aires.

His identity is based on emotional storytelling through electronic music.

His sets are:

- Progressive
- Hypnotic
- Emotional
- Groove-driven
- Cinematic
- Elegant

He carefully researches and discovers new music before every performance.

Every set is unique.

His philosophy is not playing tracks.

His philosophy is curating journeys.

That concept should drive the entire experience.

The website should never feel loud.

Never aggressive.

Never trendy.

It should feel timeless.

----------------------------------------------------
DESIGN PRINCIPLES
----------------------------------------------------

Minimalism before decoration.

Atmosphere before information.

Emotion before technology.

Silence before animation.

Space before content.

Curiosity before explanation.

Nothing exists without purpose.

Every animation must communicate.

Every interaction must have intention.

----------------------------------------------------
VISUAL LANGUAGE
----------------------------------------------------

Black is the primary color.

But use multiple blacks.

Examples:

#050505

#0B0B0B

#111111

#191919

Accent color:

Soft white

Avoid pure white whenever possible.

No gradients unless almost invisible.

No colorful backgrounds.

No glassmorphism.

No flashy UI.

----------------------------------------------------

Maximum readability.

Typography should carry the design.

----------------------------------------------------
OUTPUT
----------------------------------------------------

Do NOT generate code immediately.

First become the Creative Director.

Define:

1. Design System

2. Typography System

3. Color System

4. Spacing System

5. Motion System

6. Component Inventory

7. Page Architecture

8. User Journey

9. Wireframes

10. High Fidelity Layout

Only after the complete design direction has been approved should implementation begin.

When implementation starts, build production-quality code.

Every decision should feel intentional.

The final result should feel closer to Apple and a contemporary art museum than to a DJ website.

The website should be memorable without relying on excessive animation.

The goal is simple:

Someone should be able to recognize the website without seeing the NOV logo.
