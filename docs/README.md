# NOV — Press Kit Design Documentation

This `docs/` folder is the canonical source of truth for the NOV press kit ecosystem.

The repository is the implementation layer of a long-term creative project.

## What NOV is

- A curator of journeys, not a club act.
- A premium press kit built as an editorial experience.
- A quiet, deliberate presentation of taste.
- A website that feels closer to a museum program than a DJ landing page.

## Purpose of the repository

- Host the production website for NOV.
- Preserve the creative direction across design, motion, photography, copy, and content.
- Keep the project aligned with the existing approved direction.
- Make documentation the first step for every change.

## Philosophy

- Museum, not club.
- Curated journeys, not playlists.
- Typography and negative space are the primary visual language.
- Motion should reinforce emotion, not distract.
- Documentation drives code. Code never drives documentation.

## How documentation relates to implementation

- `docs/` records the decisions that the repository implements.
- `creative-director-brief.md` and `design-direction.md` are the approved project constitution.
- Every new feature must begin with documentation.
- If something is not decided, it is marked TODO rather than assumed.
- Existing code is evidence; the docs explain its purpose.
