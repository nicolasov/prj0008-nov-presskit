# 12 · Creative Checklist

## Visual

- [ ] The palette is grounded in black and soft white.
- [ ] Red is used only as a signal, not decoration.
- [ ] Typography is the dominant visual voice.
- [ ] Negative space is present around every section.
- [ ] The hero is calm and intentional.
- [ ] Photography reads as editorial stills.
- [ ] No glassmorphism, gradients, or influencer-style decoration.

## Motion

- [ ] All transitions are opacity-based crossfades.
- [ ] No translation, scaling, bouncing, spinning, or parallax.
- [ ] Motion reinforces emotion.
- [ ] Reduced motion is supported.
- [ ] Scroll pacing feels smooth and weighted.

## Photography

- [ ] Images feel cinematic and restrained.
- [ ] Photography avoids oversaturation.
- [ ] Crops are editorial, not generic.
- [ ] Captions are treated like subtitles.
- [ ] The hero photography is atmospheric and not flashy.

## Performance

- [ ] WebGL is dynamic-imported and deferred.
- [ ] Images use `next/image`.
- [ ] The site stays lightweight and deliberate.
- [ ] No unnecessary libraries are added.

## Accessibility

- [ ] Focus states are visible and red-bright.
- [ ] The hero DOM fallback is present for non-WebGL setups.
- [ ] The site uses a readable typographic scale.
- [ ] The tracklist is keyboard-navigable.

## Editorial

- [ ] Copy is precise and minimal.
- [ ] The voice is editorial, not promotional.
- [ ] Section labels read as cues.
- [ ] The Booking copy is clear and functional.
- [ ] Language switches preserve editorial English labels.

## Typography

- [ ] Newsreader is reserved for hero and pull quotes.
- [ ] Archivo is used for headings, bodies, navigation, forms.
- [ ] Geist Mono is used for timecodes and metadata.
- [ ] Typography hierarchy is clear through scale and opacity.

## Content

- [ ] The page reads as a journey, not a landing page.
- [ ] Each section answers one question.
- [ ] The tracklist structure is consistent across nav and sections.
- [ ] Press kit downloads are simple and useful.
- [ ] Booking feels like a conversation, not a form.

## Mobile

- [ ] Layout preserves editorial fidelity on mobile.
- [ ] Tracklist adapts to a mobile overlay.
- [ ] Hero copy remains legible at small screens.
- [ ] Images remain purposeful and not cramped.

## Hero

- [ ] The hero entrance is staged in sequence.
- [ ] The wordmark reveal is subtle and atmospheric.
- [ ] The hero photograph is revealed with scroll.
- [ ] The hero feels like a gallery opening.

## SEO

- [ ] The hero word is present in the DOM for indexing.
- [ ] Section labels and timecode metadata are clear.
- [ ] The page avoids unnecessary script bloat.

## Consistency

- [ ] Documentation is updated before implementation.
- [ ] Code reflects the documented direction.
- [ ] Visual, motion, photography, and copy decisions align.
- [ ] No new feature is added without documentation first.

## Brand

- [ ] NOV is positioned as a curator.
- [ ] Selection comes before quantity.
- [ ] Silence is part of the journey.
- [ ] Emotion comes before technology.
- [ ] Typography is stronger than decoration.
